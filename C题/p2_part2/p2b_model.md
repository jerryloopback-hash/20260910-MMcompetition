> **版本状态**：v0 首跑版（2026-09-11）。基于 `p2_part1` 交付的**点预测**（EGD 六模型集成）跑通全管线；执行与结算规则为初版，标注〔待优化〕/〔拍板项〕处后续迭代。
> **复现环境**：`pip install numpy scipy openpyxl pandas`；预测结果位于 `p2_part1/预测结果/`（勿改动，预测层由队友继续迭代）。

## 1. 问题重述与信息结构

- 电价每日相同（附件1）；小区负载与光伏功率逐日变化（附件2 实际值）。
- 每天 0:00 制定**当天计划购电策略**；微网供电不得低于负载，不足部分**紧急购电，电价 = 交易时刻电价 × 5**；除紧急购电外，购电费用**均按计划购电量计算**。
- 信息结构（与预测层交接文档一致）：0:00 只能使用**截至前一日的数据**；当天实际值仅用于结算。
- 因此 P2B = 三层：

```
预测层(p2_part1) → 计划层(逐日LP, 复用P1内核) → 执行结算层(新增, 本文重点)
   点预测L̂,P̂        计划(a,b,c,d,q)与计划购电量      实际值回放、缺口5λ结算、实际SOC轨迹
```

## 4. 计划层：逐日 LP

第 d 天（d = 2025-02-01 … 12-31）求解：

$$\min \; F_d=\sum_{k=1}^{144}\lambda_k\,(a_k+b_k)\,\Delta t$$

约束与变量同 P1（§2），输入换为预测值 L̂、P̂（按 §3.2 映射）。**SOC 边界 v0（拍板项①）**：

- E_0(d) = **前一日执行末 SOC**（由 §5 结算层回传；首日 2.1 取 6000——1 月无购电计划，储能维持附录1 初值）；
- E(24:00) = E(0:00) **钉死**（当日 SOC 中性）：既允许计划适应实际 SOC 漂移，又防止短视 LP 逐日放空储能（若 E(24) 自由，LP 会把存能耗尽省钱，把风险推给次日）。
- 备选开关：完全日重置（E_0≡6000），与滚动式做敏感性对比。

产出：当日计划 (a^p, b^p, c^p, d^p, q^p)、计划购电曲线 (a^p+b^p)Δt、计划充放电量。

## 5. 执行与结算层（紧急购电）〔v0 初版规则，待优化〕

### 5.1 设计原则

**本轮定位：预测层不参与（队友交付）；P2B 只在 0:00 用预测集做与 P1 同构的计划购电，并把紧急购电作为结算期唯一的硬约束。**

- **紧急购电 = 结算层硬约束（must-satisfy）**：题设"微网提供的电能不可低于小区负载"是不可违约的可行性要求。计划执行中任意时段供给不足负载时，缺口必须用紧急购电**强制补足**，单位成本 5λ_t（题给固定价格，无协商余地）。它不是 0:00 的决策变量，而是"预测假设未兑现"时的强制兜底——预测误差的代价据此如实落账。
- 0:00 计划全天锁定，日内除紧急购电兜底外无其他决策。购电总量 = 计划量 (a^p+b^p)，照计划计费；充放电按计划执行，仅受物理上限截断。
- **储能电量恒守 [1200, 10800]**：放电仅在触及 1200 底线时截断，绝不穿透。
- 管线 = **P1 同构 LP（输入换预测）+ 硬约束结算（缺口 5λ 强制补齐）**。不做预测修正/安全边际/随机规划——那是后续可选优化（§5.4 附注），非本轮交付。

### 5.2 逐时段执行模型（v0：计划执行 + 硬约束结算）

给定 0:00 计划 (a^p,b^p,g^p,c^p,d^p,q^p) 与实际值 (L_t, P̆_t)，时段初 SOC=E：

1. **直供**：购电直供 a^p_t 全额送达；光伏直供 g^r_t = min(g^p_t, P̆_t)；放电按计划 d^p_t（仅受物理下限截断，见 4）。
2. **硬约束（紧急购电）**：供给 S_t = a^p_t + g^r_t + d^p_t，缺口
   gap_t = max(0, L_t − S_t)，**必须全额以 5λ_t 购电补齐**（费用 = 5·λ_t·gap_t·Δt）；供电不得低于负载。
3. **充电**：c^r_t = max(0, P̆_t − g^p_t)，charge_t = min(b^p_t + c^r_t, (10800−E)/0.9, 5000·Δt)；计划外盈余（超出 b^p+c^p 之窗或装不下）→ 弃。
4. **SOC 更新**：E ← E + 0.9·charge_t·Δt − d^p_t·Δt/0.9；若电量不足致 d^p 无法全额执行，未放部分并入缺口按紧急计。全程 E ∈ [1200, 10800] 由物理上限截断保证。

要点：① 购电金额与计划完全一致；② 紧急购电是唯一的（硬）兜底，预测误差全部由此落账；③ 不引入任何预测修正或日内决策——以点预测当已知的中性基线。

### 5.4 方案B:统一费用回测选择器 + 保守度形状族(v1 已实现,首跑结果如下)

> **组内决议(2026-09-11)**:统一按 **队友的预测集 + 队友给出的分位数**(路线A/B 原设计)执行;**路线C(乘性偏置族)正式摒弃**——代码中乘性分支已移除,历史网格仅作存档(`p2b_方案B_乘性网格_历史.xlsx`);p2b 的任务 = 队友交付**三组预测(模型池组/LSTM组/XGBoost组,接口规格见 §3.4)**后**逐组求解**,以全年总费用横向比较三组预测的决策价值。分位数的具体实现以队友为准,落地后同步本节。

**框架**:选择器对一切形状族通用——对每个候选保守度,跑完整管线(计划 LP + 严格结算)得全年总费用,取最小。当前桥接形状族(队友分位数到位前的标准形态):
- **残差分位**:L̂′ = L̂ + Q_τ(滚动 56 天负载残差),P̂′ = P̂ + Q_{1−τ}(光伏残差);池深收缩 w = m/(m+7) 抗冷启动;残差池固定用**原始点预测**口径(防边际自我湮灭);一个 τ 旋钮同时控制负载(上调)与光伏(下调)两侧。

**首跑结果(2025.2.1–12.31,`p2b_solve.py` → `p2b_方案B_结果.xlsx`)**:
- 完美预见下界 **12,244,924 元/年**;L0 基线 16,825,893 元 = 计划 12,200,621 + 紧急 4,625,272(缺口 104.9 万 kWh,53% 时段)→ **预测误差代价 ≈458 万/年**;
- 桥接版 τ 曲线:0.5→16,899,421 / 0.6→16,130,278 / **0.8→15,258,462(最优 τ)** / 0.9→15,296,840;比 L0 省 **9.3%**;
- 参照:乘性族最优 (α=1.06,β=0.95) 曾得 15,221,536 元,与桥接版打平(差 0.24%)——**保守度形状不敏感,选择器才是价值主体**;
- **残差分位的适应性修复了 2 月**(τ=0.8 时 2 月比 L0 省 0.56 万;乘性族 2 月亏 3.7 万):池深收缩+小残差使 2 月边际自动变小;
- 共同结论:距下界余 ~300 万/年。队友分位数(条件分位,逐时段异质)到位后依次求解,预期能触及其中一部分;2 月的修复已示范该方向的价值。
