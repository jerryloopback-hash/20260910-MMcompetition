## 一、时段与参数（原文 §2.2、§3）

定义日历时段 **I_k = [10(k−1), 10k) 分钟，k=1..144**，即 [0:00,0:10) … [23:50,24:00)。

| 记号 | 含义 | 单位 |
|---|---|---|
| Δt | 时段长（=1/6 h） | h |
| λ_t | 外网电价 | 元/kWh |
| L_t | 小区负载 | kW |
| P_t^{PV} | 光伏发电预测功率 | kW |

附录1 储能参数：容量上限 12000 kWh，最大充/放功率 5000 kW，运行电量带 [1200, 10800] kWh，充、放电效率各 90%，0:00 初值 6000 kWh。

## 二、决策变量（原文 §4）

| 记号 | 含义 | 单位 |
|---|---|---|
| a_t | 外网购电直供负载 | kW |
| b_t | 外网购电充电 | kW |
| g_t | 光伏直供负载 | kW |
| c_t | 光伏充电 | kW |
| d_t | 储能放电供负载 | kW |
| q_t | 弃光功率（松弛量） | kW |

储电量 E_t 不作为独立变量，用"净充电累计"P_t = Σ_{s≤t}[0.9(b_s+c_s) − d_s/0.9]Δt 隐式表达，E_t = 6000 + P_t（降低规模并使 SOC 约束成为稀疏累计不等式）。

## 三、目标函数（原文 §5）

$$\min \; F=\sum_{t\in I_1..I_{144}} \lambda_t\,(a_t+b_t)\,\Delta t$$

全天购电量 = Σ(a_t+b_t)Δt，购电费 = F。
