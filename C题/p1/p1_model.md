# 问题1 数学模型（计划购电策略）

## 1. 问题重述（Q1 相关部分）

- 附件1 给出某一天（"某天"）每 10 分钟的：电价、小区负载、光伏发电预测功率。
- 每天电价与负载相同（即附件1 的这天是周期性重复的一天），光伏用预测值。
- 需求：储能 0:00 与 24:00 电量相同（附录1 初值 6000 kWh）。
- 目标：满足负载（微网供能不低于负载），最小化购电费。
- 输出：按 附件5/result1.xlsx 模板，填 144 个 10 分钟购电量 + 6 个 4 小时块的充放电量 + 0:00/24:00 储电量。

## 2. 数据约定（读题要点）

- 附件1 共 144 行数据，时间标签依次为 0:10,0:20,…,23:50,0:00+1(=24:00)。
- **标签 = 时段起点**，故 144 个时段为 [0:10,0:20)…[23:50,24:00),[24:00,24:10)。
- 问题所述"24:00 储电量"即第 143 段末（23:50–24:00 之末）的电量；
  第 144 段 [24:00,24:10) 是次日首 10 分钟，按模板仍须填写购电量，
  本模型作为当日计划的自然延续处理（其电量受容量界限约束、不参与 S24=6000 约束）。
- 时间标签与模板"计划购电量"工作表逐行对齐：行 t ↔ 时段 t。

## 3. 参数（由附件1 读入）

| 记号 | 含义 | 单位 |
|---|---|---|
| $\Delta t$ | 时段长 | h（=1/6） |
| $\lambda_t$ | 外网电价 | 元/kWh |
| $L_t$ | 小区负载 | kW |
| $P^{\mathrm{PV}}_t$ | 光伏预测功率 | kW |

## 4. 决策变量

| 记号 | 含义 | 单位 |
|---|---|---|
| $a_t$ | 外网购电直供负载 | kW |
| $b_t$ | 外网购电充电 | kW |
| $g_t$ | 光伏直供负载 | kW |
| $c_t$ | 光伏充电 | kW |
| $d_t$ | 储能放电供负载 | kW |
| $q_t$ | 弃光功率（松弛量） | kW |
| $E_t$ | $t$ 时段末储电量 | kWh |

## 5. 目标函数

$$\min \sum_{t=1}^{144} \lambda_t\,(a_t+b_t)\,\Delta t$$

## 6. 约束

1. 负载平衡：$a_t+g_t+d_t=L_t$
2. 光伏平衡：$g_t+c_t+q_t=P^{\mathrm{PV}}_t$
3. 储能动态：$E_t=E_{t-1}+0.9\,(b_t+c_t)\Delta t-\frac{1}{0.9}\,d_t\Delta t$（充、放各 90%）
4. 容量界限：$1200\le E_t\le 10800$
5. 功率界限：$b_t+c_t\le 5000$，$d_t\le 5000$
6. 边界条件：$E_0=6000$，$E_{143}=6000$（即 0:00 与 24:00 同电量）
7. 非负：$a_t,b_t,g_t,c_t,d_t,q_t\ge 0$

## 7. 求解方法

- 该问题为**线性规划（LP）**：线性目标、线性约束、连续变量。
- 采用 HiGHS 求解器（`scipy.optimize.linprog(method='highs')`，scipy 1.17 内置），
  变量数 $6\times144+144=1008$（含 E），约束约 290 等式 + 580 不等式，毫秒级求解。
- 结果验证：
  - 能量守恒恒等式（因 $E_{143}=E_0$）：
    $\sum_{t=1}^{143}(a_t+b_t)\Delta t=\sum_{t=1}^{143}(L_t-P^{\mathrm{PV}}_t)\Delta t+\sum_{t=1}^{143}q_t\Delta t+(1-0.9)\sum(b_t+c_t)\Delta t+(\frac1{0.9}-1)\sum d_t\Delta t$
  - KKT 互补松弛 / 对偶变量解释充放电阈值。

## 7.5 建模注记（求解答疑点，写入论文假设一节）

1. **90% 效率取"充、放各 90%"**（往返 0.81）。若理解为往返 90%，成本差约 8%，需在假设中明示。
2. **时段144 [24:00,24:10)**：附录5 模板要求填 144 个购电量，故保留该时段；但题中"24:00 储电量"为时段143之末，故终值约束施加于 $E_{143}$，时段144 结束后电量不受 24:00 约束（受容量界限约束）。单日 LP 无次日信息，末端 10 分钟存在轻微"末端效应"（如用存储而非低价购电），幅度极小（约 0.7% 成本），可在论文注明"若要求跨日严格定常需双日循环松弛迭代"。
3. **弃光量 $q_t$ 作为松弛变量保留**：本例最优恒为 0（光伏盈余 6248 kWh < 可用容量 9600 kWh，无强约束弃光），其含义"该日裕量充足、无需弃光"是一句可写进结论的观测。
4. **无需 0-1 变量**：效率<1 时边充边放必亏，LP 自动规避（已验证 0 时段）。

## 8. 输出约定（result1.xlsx）

- "计划购电量"：行 t 填时段 t 购电量 $=(a_t+b_t)\Delta t$（kWh）。
- "充放电量"：6 个块（0–4,4–8,…,20–24 点），充电量 $=\sum b_t+c_t$ 输入电能量（kWh），
  放电量 $=\sum d_t$（kWh）；0:00 与 24:00 储电量均为 6000。
