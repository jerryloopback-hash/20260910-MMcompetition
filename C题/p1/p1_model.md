# 问题1（P1）数学模型：计划购电策略

> **版本状态**：v2 日历对齐修订版（2026-09-11）。本目录下 `result1.xlsx`、`_traj.npy` 为 v1（旧对齐）产物，在装有依赖的机器上重跑 `p1_solve.py` 后刷新。
> **复现环境**：`pip install numpy scipy openpyxl`，运行 `python p1_solve.py`（路径已相对脚本定位，无硬编码）。

## 1. 问题重述（P1 相关部分）

- 附件1 给出某一天（"某天"）每 10 分钟的：电价、小区负载、光伏发电预测功率。
- 每天电价与负载相同（即附件1 的这天是周期性重复的一天），光伏用预测值。
- 需求：微网供电逐时段不低于负载；储能 0:00 与 24:00 电量相同（附录1 初值 6000 kWh）。
- 目标：满足负载约束下最小化全天购电费。
- 输出：按 附件5/result1.xlsx 模板，填 144 个 10 分钟购电量 + 6 个 4 小时块的充放电量 + 0:00/24:00 储电量。

## 2. 数据读取与时段对齐（v2 修订核心）

### 2.1 附件1 的真实结构

附件1 共 144 行数据，粒度 10 分钟。时间列**前 60 行是数值（天内小数，0:10→10:00），后 84 行是共享字符串文本（"10:10"→"24:00"）**——直接按数值解析后 84 行会得到错误的"字符串索引"数据，解析时必须区分类型（pandas/openpyxl 会自动处理；本目录曾因此误判数据"跳变"）。行标签语义为**时段起点**：第 1 行标 0:10 = 时段 [0:10,0:20)，……，第 143 行标 23:50 = [23:50,24:00)，第 144 行标 0:00+1（=次日 0:00）= [24:00,24:10)。

### 2.2 日历时段定义与数据映射

定义日历时段 **I_k = [10(k−1), 10k) 分钟，k=1..144**，即 [0:00,0:10) … [23:50,24:00)。数据映射：

| 日历时段 | 数据来源 | 依据 |
|---|---|---|
| I_1 = [0:00,0:10) | 附件1 第 144 行（标签 0:00+1） | 该行是次日首 10 分钟；由"每天电价/负载相同 + 光伏预测为同一日曲线"的**逐日周期性**，其数值与当日 [0:00,0:10) 完全相同 |
| I_k（k=2..144） | 附件1 第 k−1 行 | 标签=时段起点，直接对应 |

映射后 144 个日历时段恰覆盖当日 0:00–24:00，无缺失、无重叠（已用脚本对附件1 全部行标签做自测验证）。

### 2.3 为什么放弃 v1 的对齐（问题记录，供论文"模型修订"叙述）

v1 直接把附件1 的 144 行当作优化时段（即 [0:10,0:20)…[24:00,24:10)），并在时段 143 末（=24:00）钉 E=6000、时段 144 末端 E 自由。后果：

1. **末端效应**：时段 144 [24:00,24:10) 在目标函数里"后面没有明天"，LP 把储能偷放到 5362 kWh（该段购电 0、放电 574 kWh）——方案**不可逐日复制**（明天 0:10 的初始电量不再是 6000），与"每天制定同一策略"的题设矛盾；目标函数同时少计约 245 元。
2. **表2 自洽性破裂**：v1 表2 六块回推 ΔSOC = 0.9×Σ充 − Σ放/0.9 = −637.9 kWh ≠ 0，与表内"0:00/24:00 储电量均为 6000"直接矛盾，评委复算即可发现。
3. **窗口错位**：v1 的 4 小时块实际覆盖 [0:10,4:10) 等 +10 分钟偏移窗口，且第 6 块混入了跨日段。

v2 用日历对齐 + **E(0:00)=E(24:00)=6000 双端钉死**，三类问题同时消失：末端效应不存在（[0:00,0:10) 是正常的日谷充电段，其充电价值通过次日早峰完整进入目标函数）；表2 块与日历窗口精确对齐；模板末行获得自然解释（见 §8）。

### 2.4 模板行映射

模板"计划购电量"共 144 数据行，标签 0:10-0:20 … 23:50-0:00+1、0:00+1-0:10+1：

- 行 r（r=2..144）↔ 日历时段 I_r（标签起点 10(r−1) 分钟，与 I_r 定义一致）；
- 行 145（0:00+1-0:10+1 = 次日 [0:00,0:10)）↔ **I_1 的周期镜像**：由于逐日执行同一策略，次日首段的购电量等于当日 I_1 的购电量，直接复制填写。

因此报告的 144 个购电量按周期平移恰好覆盖全部时间——模板、附件1、优化模型三者完全闭合。

## 3. 参数（由附件1 读入，按 §2.2 映射到 I_1..I_144）

| 记号 | 含义 | 单位 |
|---|---|---|
| Δt | 时段长（=1/6 h） | h |
| λ_t | 外网电价 | 元/kWh |
| L_t | 小区负载 | kW |
| P_t^{PV} | 光伏发电预测功率 | kW |

附录1 储能参数：容量上限 12000 kWh，最大充/放功率 5000 kW，运行电量带 [1200, 10800] kWh，充、放电效率各 90%，0:00 初值 6000 kWh。

## 4. 决策变量（每时段 6 个 + 隐式 SOC）

| 记号 | 含义 | 单位 |
|---|---|---|
| a_t | 外网购电直供负载 | kW |
| b_t | 外网购电充电 | kW |
| g_t | 光伏直供负载 | kW |
| c_t | 光伏充电 | kW |
| d_t | 储能放电供负载 | kW |
| q_t | 弃光功率（松弛量） | kW |

储电量 E_t 不作为独立变量，用"净充电累计"P_t = Σ_{s≤t}[0.9(b_s+c_s) − d_s/0.9]Δt 隐式表达，E_t = 6000 + P_t（降低规模并使 SOC 约束成为稀疏累计不等式）。

## 5. 目标函数

$$\min \; F=\sum_{t\in I_1..I_{144}} \lambda_t\,(a_t+b_t)\,\Delta t$$

全天购电量 = Σ(a_t+b_t)Δt，购电费 = F。

## 6. 约束

1. 负载平衡：a_t + g_t + d_t = L_t（等式不失一般性：多供无益，LP 自动取等）
2. 光伏平衡：g_t + c_t + q_t = P_t^{PV}
3. 储能动态：E_t = E_{t−1} + 0.9(b_t+c_t)Δt − (d_t/0.9)Δt（充、放各 90%，往返 0.81）
4. 容量界限：1200 ≤ E_t ≤ 10800（所有节点）
5. 功率界限（**并网侧口径**，见注记 5）：b_t + c_t ≤ 5000，d_t ≤ 5000
6. 边界条件：E_0 = 6000（附录1 初值）；E_144 = 6000（0:00 与 24:00 储电量相同 + 逐日重复 + 初值 6000 ⇒ 终值必为 6000）
7. 非负：a_t, b_t, g_t, c_t, d_t, q_t ≥ 0（不售电：购电量与放电量均不可为负；放电被 a,g ≥ 0 自动限制在 d_t ≤ L_t 内，不会反送外网）

## 7. 求解方法

- 模型为标准 **LP**：变量 6×144 = 864（E 以累计和隐式表达），等式约束 2×144+1，不等式约束 4×144。
- 求解器：**HiGHS**（经 `scipy.optimize.linprog(method='highs')` 调用），毫秒级。
- 结果校验清单（脚本自动执行）：
  1. E(24:00) = 6000（断言）；
  2. 全天能量守恒恒等式：购电+光伏 = 负载+弃光+充损+放损；
  3. 无同段边充边放（计数 = 0）；
  4. 表2 自洽：0.9×Σ充电量 − Σ放电量/0.9 ≈ 0 = E(24:00)−E(0:00)；
  5. 对偶/影子价格提取 + KKT 互补松弛校验 + 有限差分交叉验证（§9）；
  6. 写入 xlsx 后按**发布值（舍入后）**复算全天购电量。
- 弃光 q_t 作松弛保留。本例最优解 q ≡ 0：全天光伏盈余远小于可充容量与负载转移能力之和，"该日裕量充足、光伏全额消纳"是可写入结论的观测。

## 7.5 建模注记（写入论文假设与说明一节）

1. **效率口径：充、放各 90%**（往返 0.81）。若理解为往返合计 90%，成本差约 8%。90% 只作用于进出储能的路径，购电/光伏直供负载不打折（题目只给了储能效率）。
2. **时段对齐与周期性**（v2 修订，见 §2）：I_1 用附件1 第 144 行数据的合法性来自逐日周期性——每天电价、负载相同，光伏预测为同一日曲线，故"次日 0:00-0:10"与"当日 0:00-0:10"数据相同。该假设应在论文中显式声明。v1 的跨日段末端效应（不可逐日复制、表2 差 −638 kWh）由此修订消除；预期改善为目标函数口径 ≥245 元/日，加上 [0:00,0:10) 恢复正常谷段充电后的重优化空间，合计约 1–2%（以重跑为准）。
3. **弃光**：作为松弛变量保留；本例最优恒为 0（见 §7 校验清单）。
4. **无需 0-1 变量排除"边充边放"**：由 §9 对偶分析，同时充放要求节点边际价值 γ_t 与电价同时为零，正电价下 LP 自动排除（脚本对最优解逐段复核为 0 段）。
5. **功率上限 5000 kW 取并网侧（母线端）口径**：充电时从母线取电 ≤5000 kW（计入变流器损耗后电池实际存入 4500 kW）；放电时馈入母线 ≤5000 kW（电池实际放出 5556 kW）。理由：①储能系统额定功率的行业惯例是交流端铭牌值；②与"效率损耗发生在变流器"的物理图像自洽；③充/放两方向在母线电表上对称，与题面单一数值表述匹配。敏感性：放电峰值 4294 kW，两种口径（并网侧 5000 / 电池侧 4500 送达）均不触顶；**充电有 19 个时段顶格 5000 kW**，若改用电池侧口径（母线可取 5556 kW）成本约再降 1%——该口径影响报出数字，论文假设必须写明。
6. **表2 记账口径（口径乙）**：充电量 = Σ(b_t+c_t)Δt（并网侧输入电能量），放电量 = Σd_tΔt（并网侧送达电能量）；于是 0.9×充电量 − 放电量/0.9 = 储电量变化，表2 与储电量列自洽。放电量≠负载（负载由购电直供+光伏+放电三源共同满足）。
7. **多重最优**：144 段电价有 143 个互异值（仅 1 处两段同价），LP 最优解在报告量（购电量、费用、充放电量）上基本唯一；a/b（购电去向）与 g/c（光伏去向）的拆分退化不影响任何报告量。

## 8. 输出约定（result1.xlsx）

- "计划购电量"：行 r（2..144）填 I_r 购电量 (a_r+b_r)Δt（kWh）；行 145 填 I_1 的周期镜像值（§2.4）。
- "充放电量"：6 个块与日历窗口对齐（0-4,4-8,…,20-24 点 = I_{24k+1}..I_{24k+24}）；充电量 = Σ(b+c)Δt，放电量 = Σd·Δt（口径乙，注记 6）；0:00 与 24:00 储电量均填 6000。
- 表1（论文）：全天购电量 = Σ_{I_1..I_144}(a+b)Δt，购电费 = F；六个指定时段 10:00-10:10 … 20:00-20:10 对应 I_61、I_73、I_85、I_97、I_109、I_121（模板行 61/73/85/97/109/121）。
- `_traj.npy` 存档行序：a, b, g, c, d, q, a+b, SOC[1..144], γ（节点边际价值，若 scipy 返回对偶）。

## 9. 对偶分析：影子价格与充放电阈值（论文素材）

### 9.1 出发点：LP 的解为什么长这样

LP 求出的计划呈现清晰的块结构：夜谷充电（0:10-1:10 顶格）、午间光伏充电、早晚双峰放电、其余时段按需直购、中午光伏自给后购电为 0。LP 并不懂"低买高卖"——这些结构由**对偶变量（影子价格）**严格决定。本节把直觉变成可检验的互补松弛条件，既是最优性的独立验证，也是论文中解释机制的核心素材。

### 9.2 对偶变量一览与节点边际价值

给各类约束挂上拉格朗日乘子：负载平衡 α_t（**边际供电成本**，即瞬时现货价 σ_t = α_t/Δt）、光伏平衡 β_t（光伏的边际机会价值）、SOC 上下界 η_t, θ_t ≥ 0、充/放功率上限 π_t, ρ_t ≥ 0、全天归零约束的影子价 ϖ。

核心量是**节点边际价值 γ_t**——在节点 t（时段 t 末）白得 1 kWh 储能可节省的费用：

$$\gamma_t = \gamma_{t+1} - \eta_t + \theta_t,\qquad \gamma_{145}:=\varpi$$

递推读法（与 §9.4 数值曲线互相印证）：

- **内点节点**：γ 逐段不变——能量躺在罐里不生息，价值跨时间守恒；
- **满罐节点**（η_t > 0）：γ 向下台阶——罐满时多出的 1 kWh 挤占罐容，价值被"上限稀缺"的影子价削低；
- **空罐节点**（θ_t > 0）：γ 向上台阶——能量枯竭边缘，1 kWh 格外珍贵。

γ 的水平由充电/放电条件在窗口两端"锚定"（下述 9.3），因此整条 γ 曲线是分平台、在充放窗口间爬坡的阶梯状曲线——它就是**储能在各时刻的影子价格**，是论文中最能体现"模型在思考"的一张图（γ_t 与 λ_t 同轴对比）。

### 9.3 三条经济判据（KKT 互补松弛）

以 σ_t 记节点 t 的边际供电成本（a_t>0 时 σ_t = λ_t；放电自给时 σ_t = γ_t/0.9 + ρ_t/Δt）：

| 决策 | 互补松弛条件 | 经济读法 |
|---|---|---|
| 充电 b_t+c_t > 0 | λ_t = 0.9γ_t − π_t/Δt | 买入 1 kWh → 存入 0.9 kWh，存入价值恰好等于电价；功率顶格时出现正溢价 π/Δt |
| 放电 d_t > 0 | σ_t = γ_t/0.9 + ρ_t/Δt | 放出 1 kWh 送达 0.9 kWh，其价值恰好等于边际供电成本 |
| 空闲 | 0.9γ_t − π_t/Δt ≤ λ_t ≤ γ_t/0.9 + ρ_t/Δt | **迟滞带**：现价落在 [0.9γ, γ/0.9] 内时不动作——带宽因子 1/0.81 就是往返损耗造成的"无套利区间" |

推论一（**套利阈值**）：从时段 s 充、时段 t 放，中间无边界节点时 γ_s = γ_t，联立两等式得 λ_t/λ_s ≥ 1/0.81 ≈ **1.2346**：价差比不足 1.2346 的两段之间绝不搬运能量。这是全部启停决策的统一判据。

推论二（**无同充同放**）：同段既充且放要求 λ_t = 0.9γ_t 且 λ_t = γ_t/0.9 同时成立 ⇒ γ_t = 0 且 λ_t = 0。本题电价恒正，故最优解必无同段充放——这就是注记 4 的理论依据，无需引入 0-1 变量。

推论三（**弃光条件**）：q_t > 0 ⟺ β_t = 0 ⟺ 光伏边际价值为零（罐满且负载已满覆盖）。本例 q ≡ 0 说明每一 kWh 光伏都被消纳。

### 9.4 数值验证（脚本自动生成，重跑后刷新）

脚本对最优解逐段校验 9.3 的互补松弛（充电段等式、放电段等式、空闲段迟滞带），并输出：

1. γ_t 全天曲线（范围、台阶位置），与 λ_t 对比；
2. 充/放窗口表：起止、电量、λ 范围、γ 范围——每个放电窗口与其充电来源的价差比应 ≥ 1.2346，功率顶格段（19 个）的 γ 溢价 π/Δt > 0 应可见；
3. 对偶符号的**有限差分交叉验证**：抽样 8 个内点节点，把节点净充电累计钉在 +5 kWh 重解 LP，目标函数斜率应等于 −γ_t（两种独立方法一致，排除对偶符号约定错误）。
