## 1. 核心方法论：为什么是分位数

### 1.1 预测分布 vs 点摘要的选取

- 预测层真正客观的产出是**条件分布** F(D)，不是"一个数"。
- 从分布里取哪个点喂给优化器是一个**决策**，最优点摘要取决于下游损失：MSE → 均值；MAE → 中位数；**不对称线性损失 → 特定 τ 分位数**。
- "预测不随优化目标改变"这一原则**对分布成立、对点预测不成立**。"取均值"只是对称损失下的特例，不是中立圣杯。

### 1.2 为什么不对称必须安放在预测层

本管线中紧急购电**不是优化器的决策变量**，而是"实际缺口"触发的结算后果——5 倍价信息根本不进入优化器。不对称代价要么放进预测层（分位数法，便宜），要么放进优化层（场景法/两阶段随机规划，原则性做法）。当前两段式管线没有优化层入口，故采用分位数法；它同时是随机规划的廉价影子/入门版，不冲突。

### 1.3 报童骨架（τ 取值的依据）

单时段、忽略储能：计划 x，实际净需求 D。

- 计划少了：缺口按 5p 购而非 p，边际损失 **c_u = 4p**
- 计划多了：多付 p，但盈余**可充储能回收**（回收价值 s ≤ p），边际损失 **c_o = p − s**
- 临界分位点：F(x\*) = c_u/(c_u + c_o) = 4p/(4p + p − s) = **4/(5 − s/p)**

解读：s=0（盈余全浪费）时 x\* = 80%，是**下界锚点**；储能裕度越大、s 越接近 0.9p，最优分位越高（s=0.9p 时 ≈97.6%），且随 SOC 状态变化。**实践路线：不做解析求解，扫 τ ∈ {0.5, 0.6, 0.7, 0.8, 0.9} 做全年回测，用总费用曲线选 τ\***。

⚠️ 目标是**最小化期望总费用**，不是消灭紧急购电——τ→100% 是错误的；最优 τ\* 下通常仍会有一些紧急购电（罕见极端缺口挨 5 倍价比每天过量购买划算）。

## 2. 两条实现路线

**路线 A（正规版）：分位数训练**
1. LightGBM 逐 τ 训练：`objective='quantile', alpha=τ`，每个 τ 一个模型。
2. 特征：日历项（时刻、星期、day-of-year 傅里叶项）+ 滞后（1/7/14/28 天同时刻）+ 滚动统计；**144 时段池化训练**（时刻本身做特征），勿逐时段建 144 个模型。
3. 校准检验：回测检查"τ 分位数是否覆盖 τ 比例的实际值"（经验覆盖率/PIT 直方图），不覆盖则重新校准——论文严谨性亮点。

**路线 B（廉价版，先跑通）：均值预测 + 残差分位修正**
预测 = 均值 + Q_τ(滚动窗口残差)。不改训练代码，直接扫 τ 出"费用 vs τ"曲线。时间紧时完全站得住。

**评估两层指标**：预测层用 pinball loss / MAE（与成本无关、可独立评估）；管线层用**总费用、紧急购电量**（决策相关，终极指标）。滚动起点回测 2025.2–12。

**年周期冷启动**：年周期从未被完整观测（2 月只见 1 月），2–5 月光伏爬坡学不到，存在系统性冷启动偏差。宜保守（相似日限制邻近日期），论文可主动量化"冷启动代价"。

## 3. ★ QRA 详述（本文档重点）

### 3.1 定位与出处

QRA（Quantile Regression Averaging，分位数回归平均）：Nowotarski & Weron (2015) 提出，用于电力现货价格预测区间，GEFCom 系列竞赛 probabilistic 赛道的主流手段（写作引用前建议用 Tavily 核对原文信息）。

与直觉相反的核心思想：**不是先组合点预测、再从组合序列取分位数，而是在每个 τ 水平上直接做线性组合**。每个 τ 拥有独立的一套权重向量——低分位可能更倚重保守的基模型，高分位倚重另一个。经验上 QRA 优于"先组合后取分位"。

### 3.2 机制（四步）

设基模型池 M 个（例如：相似日法、季节性朴素、Holt-Winters/ETS、SARIMA+傅里叶、GBDT 均值版）。

1. **构造基预测矩阵**：对每个回测起点日 d，各基模型输出全天 144 点预测。
2. **设计矩阵**：行 = (回测日 × 144 时段) **池化**（早期数据少，勿逐时段拟合），目标列 = 实际值 y，协变量 = 各基模型对同时刻的预测（可加日历项）。协变量建议不设截距或保留截距视数据而定。
3. **逐 τ 拟合线性分位回归**（pinball loss，见 3.4）：τ 取网格，如决策层用 {0.5, 0.6, 0.7, 0.8, 0.9}，若要给后续场景法供样可加密到 {0.05,…,0.95}。得到每 τ 一套系数（M 维权重，可选非负约束）。
4. **应用**：把拟合出的 τ-系数作用于未来各基模型预测，得到组合后的 τ 分位数预测；逐 τ 重复即得整族分位数曲线。

### 3.3 与"时变权重组合 + ML 学权重（元学习/NN）"的关系（给接手者的关键提示）

- **QRA 本身就是一种"ML 学权重"方案**：线性分位回归从校准数据里学出各基模型的组合权重——它是元学习/神经网络仲裁的**线性、逐 τ 特例**，也是必须先跑通的 baseline。
- 顺序建议：先 QRA（一天内可跑通）→ 再上非线性版（元学习/NN 输出逐 τ 权重）→ 只有在 pinball loss 与下游费用**双双胜出**时才替换。
- **冷启动期 QRA 是优势项**：每 τ 仅 M(±1) 个参数，31 天训练窗口下不易过拟合；NN/元学习此期极易过拟合，若上需强正则 + 跨 τ 平滑（相邻 τ 的权重应缓变）。
- 校准窗口的滑窗重拟合（下条）**就是"时变权重"的原则化实现**——权重随近期回测表现自动漂移，无需手调"数据量→权重"映射。

### 3.4 实现细节与坑

- **滑窗校准**：在每个预测日，用最近 K 个回测起点（建议 K=28–60 天）重拟合 QRA 系数，逐日或每周重拟合。线性分位回归拟合开销极小，逐日无压力。
- **防泄漏**：校准窗口只能用严格早于预测起点的（基预测, 实际）对；基模型的滚动回测不得用到未来信息。
- **pinball loss**：L_τ(y, ŷ) = max{τ(y−ŷ), (τ−1)(y−ŷ)}，即 y≥ŷ 时取 τ·(y−ŷ)，y<ŷ 时取 (1−τ)(ŷ−y)。
- **分位数不相交（crossing）**：独立拟合的各 τ 曲线可能交叉。修复：重排法（rearrangement，Chernozhukov 等）对每时刻的分位数曲线排序；或粗网格拟合 + 单调插值。
- **非负权重约束**（可选）：保留"组合权重"的可解释叙事；不加约束精度可能略好但难解释。论文可两种都报告。
- **基线对比组**：简单平均、逆近期误差加权、平方损失 stacking——论文中展示 QRA 在覆盖率校准与下游费用上胜出。
- **产物复用**：QRA 输出的整族分位数同时服务 ① τ 扫描决策层（第 1.3 节）② 后续问题3/随机规划升级时的场景生成（从分位数函数采样）。
- 负载与光伏各建一套 QRA（分开建模原则不变）。

## 4. 论文写作要点（浓缩）

三层叙事：**预测层**（成本无关，pinball 评估）→ **决策层**（报童临界比分位点推导；明确"均值只是对称损失特例"，把"预测是否应随目标改变"的方法论质疑写成讨论节，是加分项）→ **经验校准**（τ 扫描费用曲线、紧急购电量 vs 过购浪费的此消彼长图、覆盖率校准图）。

消融对照：均值 / 中位数 / τ\* 三种点预测喂同一个优化器，报告总费用差异 = "分位数升级值多少钱"。

术语点缀：critical fractile、pinball loss、predict-then-optimize、两阶段随机规划（原则性参照）、QRA（Nowotarski & Weron）。不必真做端到端 SPO。

问题3 联动预告：调整机制（违约 0.5 倍、超买 1.5 倍）同样是双向不对称损失，本套分位数决策逻辑原样迁移。
