# 微网日前功率预测模块 — 国赛提交附件

## 一、项目概述

本模块为2026年全国大学生数学建模竞赛C题（微网与外部电网电力调控策略）问题2的预测部分。

**预测任务**：每天0:00用截止前一天的历史数据，预测当天144个10分钟时点的小区负载功率与光伏发电实际功率。预测期2025-02-01至2025-12-31（334天），初始仅1月31天数据（冷启动），滚动执行。

**核心方法**：异构模型池（负载5模型+光伏5模型）+ EGD在线时变权重集成 + 分位数预测与报童模型对接。

**全期结果**：负载MAE=162.99（MAPE=3.80%），光伏MAE=165.96（白天MAPE=8.85%）。

## 三、代码运行方式

### 环境依赖
- Python 3.10+
- 核心库：numpy, pandas, scikit-learn, statsmodels 0.15.0, lightgbm, xgboost 3.4.1, torch 2.14.0（LSTM用）
- 安装：`pip install numpy pandas scikit-learn statsmodels lightgbm xgboost torch openpyxl`

### 运行顺序
1. **快速验证**：`python _test_v5.py`（2-3月59天，约20秒，验证流程正确性）
2. **全量预测**：`python 预测_v5_扩展模型池.py`（334天，约35分钟，生成点预测+误差报告+权重演化）
3. **消融实验**：`python _ablation_v5.py`（秒级，基于逐模型预测数组重算EGD）
4. **过拟合诊断**：`python _overfit_v5.py`（约2分钟）
5. **分位数预测**：`python _quantile_v5.py`（约2分钟，需先跑完全量预测）
6. **LSTM对照**：`python _lstm_baseline.py`（约30秒）
7. **XGBoost对照**：`python _xgb_baseline.py`（约90秒）

### 数据路径
脚本中数据路径为 `D:\CUMCM2026Problems\C题\附件\附件2.xlsx`，复跑时需修改为本地实际路径。

## 四、模型池与方法说明

### 负载模型池（5个）
| 模型 | 原理 | 全期MAE |
|---|---|---|
| SeasonalNaive | 上周同刻值 | 176.80 |
| HistMean | 近4周同刻均值 | 188.88 |
| STL | 趋势阻尼外推+季节取上同相位 | 178.59 |
| kNN | 相似日曲线匹配（限同星期几） | 188.80 |
| LightGBM | 梯度提升树（18维特征，强正则） | 172.71 |
| **EGD集成** | **在线指数梯度下降时变权重** | **162.99** |

### 光伏模型池（5个）
| 模型 | 原理 | 全期MAE |
|---|---|---|
| Persistence | 昨日同刻值 | 185.35 |
| kNN | 相似日曲线匹配（不限星期几） | 205.04 |
| STL | 趋势阻尼外推+季节取上同相位 | 212.73 |
| FPCA | 函数型主成分分析，阻尼score persistence | 160.71 |
| LightGBM | 梯度提升树+夜间强制置0 | 192.14 |
| **EGD集成** | **在线指数梯度下降时变权重** | **165.96** |

### EGD在线权重
- 指数梯度下降（OneNet, NeurIPS 2023）：w_{t+1,i}=w_{t,i}·exp(-η·ℓ̃)/Z，η=0.005
- 局部核加权损失（TVJMA, J.Econometrics 2020）：30天窗口指数衰减λ=0.95
- K步重初始化：每7天混合初始权重，α=max(0.05, 0.5·exp(-(N-35)/60))

### 分位数与报童模型
- 滚动30天窗口经验分位数：P10/P50/P83.3/P90
- 报童最优分位=Cu/(Cu+Co)=5/(5+1)≈0.833（低估代价5倍电价/高估代价1倍）
- P83.3建议日均购电391,012 kWh，比点预测多购3.6%
